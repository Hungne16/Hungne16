# Profile artwork

Banner: generated using the built-in ImageGen tool for this profile.

Prompt: Monochrome stipple and ordered-dithering pixel art of two sculptural hands reaching toward a tiny star, one dissolving into pixels and one subtly mechanical, with faint vintage computer window outlines on a near-black background. No text or logos.

Technology icons: https://github.com/tandpfun/skill-icons (MIT; license in icons/LICENSE).
Framer mark: https://simpleicons.org (CC0).

The banner is static PNG; design-motion.svg and tools-motion.svg add vector motion, alongside the divider and metrics.

Motion assets: authored SVG/CSS animation, generated by scripts/generate-motion.js.
Run npm run motion after changing the source. Logos are embedded as vector paths, without external image dependencies.
The design study uses layered affine projections and metallic gradients to suggest 3D depth. It is a decorative animation, not an interactive design editor.
Both motion assets respect prefers-reduced-motion.
